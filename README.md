# Issue Tracker - App Trilhos Portugal

Uma aplicação web para gestão e rastreamento de tarefas/issues (Kanban board) para a App Trilhos Portugal.

## 🚀 Funcionalidades

- **Quadro Kanban**: Organização de tarefas em diferentes estados (A Fazer, Em Progresso, Concluído, etc.).
- **Filtros e Pesquisa**: Filtre por Épico, Responsável, Status e Pesquisa textual.
- **Gestão de Tarefas**: Adicionar, editar, mover e eliminar tarefas/issues.
- **Importação/Exportação**: Suporte para carregar e exportar dados do projeto.

## 🛠️ Tecnologias Utilizadas

- HTML5 / CSS3 / JavaScript (Vanilla)
- Interface Responsiva com Design Moderno

## 📖 Como Usar

Basta abrir o ficheiro `index.html` em qualquer navegador web moderno.
