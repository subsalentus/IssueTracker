# IssueTracker

A minimalist task and project manager featuring Kanban boards, Sprint planning, Backlog management, options dropdown menu, and a Portuguese / English flag dropdown menu (`🇵🇹 PT` / `🇬🇧 EN`).

## What it does

**IssueTracker** allows you to create and organize projects, manage tasks on Kanban boards, plan Sprints/Releases in the Backlog, expand the options dropdown menu for CSV import/export and project actions, switch seamlessly between Portuguese and English via the header flag dropdown, and track team progress simply and intuitively.
