# IssueTracker - Multi-Project Jira Kanban

Aplicação web inspirada no Jira para gestão avançada de tarefas, múltiplos projetos, colunas personalizadas e quadros Kanban.

## 🚀 Funcionalidades

- **Múltiplos Projetos**: Gestão de vários projetos independentes com chaves de ID personalizadas (ex: `TRL-`, `MOB-`, `WEB-`).
- **Colunas Dinâmicas**: Adicionar, renomear e eliminar colunas do quadro Kanban por projeto.
- **Tipos de Issue**: Suporte para Task 📑, Bug 🐛, Story 📖, Epic ⚡ e Feature 🌟.
- **Checklist de Subtarefas**: Adicionar e marcar subtarefas dentro do modal da tarefa com barra de progresso no cartão.
- **Pontos de História (Story Points)**: Estimativas baseadas em Fibonacci (1, 2, 3, 5, 8, 13 pt).
- **Atribuição de Membros (Assignee)**: Identificação visual de membros responsáveis.
- **Filtros e Pesquisa em Tempo Real**: Filtragem combinada por Épico, Tipo, Prioridade e Pesquisa textual.
- **Modo Escuro / Claro**: Alternância de temas visuais com persistência em local storage.
- **Importação e Exportação CSV**: Suporte para backup e importação por projeto.
