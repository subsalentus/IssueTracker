# IssueTracker

Aplicação web para gestão de tarefas e issues (Kanban) da App Trilhos Portugal.

## 🚀 Funcionalidades

- **Quadro Kanban Interativo**: Organização de tarefas por colunas (To Do, In Progress, Done) com Drag & Drop.
- **Edição e Eliminação Individual**: Modal para editar título, descrição, épico, prioridade e estado de cada tarefa.
- **Prioridades**: Níveis de prioridade (Alta 🔴, Média 🟡, Baixa 🟢) com badges visuais.
- **Filtros e Pesquisa em Tempo Real**: Pesquisa textual por ID/Título/Descrição e filtros por Épico e Prioridade.
- **Modo Escuro / Claro**: Suporte a temas visuais com persistência.
- **Importação e Exportação CSV**: Guardar e carregar dados facilmente.
