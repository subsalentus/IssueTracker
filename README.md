# IssueTracker - Modern & Minimalist Jira Kanban

Aplicação web limpa e minimalista para gestão avançada de tarefas, múltiplos projetos, colunas personalizadas e quadros Kanban.

## 🚀 Funcionalidades

- **Interface Minimalista**: Interface despoluída com navegação simples por botões e menus suspensos.
- **Criação Rápida por Modal**: Botão principal `+ Nova Tarefa` para criar e configurar tarefas sem poluir o ecrã.
- **Filtros Expansíveis**: Barra de pesquisa e filtros rápida acionável pelo botão `🔍 Filtros`.
- **Menu de Opções**: Menu `⚙️ Opções` centralizado para importação/exportação CSV e eliminação de projetos.
- **Múltiplos Projetos**: Gestão de vários projetos com chaves personalizadas (ex: `TRL-`, `MOB-`).
- **Colunas Dinâmicas**: Adicionar e gerir colunas personalizadas no quadro Kanban.
- **Tipos de Issue e Subtarefas**: Suporte para Task 📑, Bug 🐛, Story 📖, Epic ⚡, Feature 🌟, Story Points e checklist de subtarefas.
